# Brand Assets

Shared logos and banners for Sharp Matrix repositories under G.C.A.

Same Sharp SIR visual marks as used across the platform (copied for this org home).

## Available Assets

| Asset | File | Use |
|---|---|---|
| Logo (blue background, PNG) | `logo-blue.png` | Primary — org profile, READMEs, light & dark mode |
| Logo (white text, PNG) | `logo-white.png` | For dark backgrounds only |
| Logo (white text, SVG) | `logo-white.svg` | Vector version for dark backgrounds |
| Logo (dark text, SVG) | `logo-dark.svg` | Vector for light backgrounds |
| Icon | `icon.jpg` | Org avatar / favicon-style use |
| Banner template | `banner-template.svg` | Social / header banners |

## Usage in READMEs

Reference via raw URL:

```
https://raw.githubusercontent.com/gca-global/.github/main/brand/FILENAME
```

### Primary logo (works everywhere)

```html
<p align="center">
  <a href="https://sharp-matrix.com/">
    <img src="https://raw.githubusercontent.com/gca-global/.github/main/brand/logo-blue.png" alt="Sharp Matrix" width="400" />
  </a>
</p>
```
